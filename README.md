# Clothez - Secure E-Commerce Website

**Live Site:** https://csce5560clothez.xyz

## Project Overview
Clothez is a secure e-commerce platform for streetwear clothing built 
with WordPress and WooCommerce, hosted on InfinityFree.

## Features
- Product catalog with categories (Tops, Bottoms, Shoes)
- Secure checkout via WooCommerce
- User account creation and login
- Two-Factor Authentication (2FA)
- SSL/HTTPS security

## Tech Stack
- **Platform:** WordPress
- **Hosting:** InfinityFree
- **E-Commerce:** WooCommerce
- **Security:** 2FA Plugin, SSL Certificate
- **Domain:** csce5560clothez.xyz

## Security Features
- Two-Factor Authentication for user accounts
- WooCommerce secure payment processing
- HTTPS enforced via SSL
- Password-protected admin area

## Site Structure
- Homepage with featured products
- Shop page with category navigation
- Cart & Checkout flow
- My Account / Login portal
